## Locked design

- Preserve all 22 beat IDs and order, prerequisites, completion signals, hints, line IDs, flags, persistence and evidence.
- Editor-only JSON parsing. Runtime loads `Resources/Tutorial/FirstHourContract`.
- No runtime JSON parser.
- No hard-coded fallback beat list.
- SHA-256 is computed from the approved source-file bytes and stored on the asset.
- Import is create-or-update and deterministic.
- Invalid data fails closed with stable codes; it does not overwrite a valid asset.
- Missing asset disables tutorial orchestration only. Base gameplay remains available.
- Audit findings are WARN-only:
  - `FIRST_HOUR_CONTRACT_ASSET_MISSING`
  - `FIRST_HOUR_CONTRACT_ASSET_DRIFT`
  - `FIRST_HOUR_CONTRACT_ASSET_INVALID`
