# THE SLIPWAY — the cloneable framework (parallel to Ziptide; touches nothing)

`Stage: pre-pipeline (Slipway) · Type: research`

**What this folder is:** the extracted, game-agnostic framework — "the structure you build
every ship on" (`docs/design/ONE_SHOT_FRAMEWORK.md` T5). Ziptide is the first ship; the
Slipway is what the NEXT game clones. Long-term (Terry, 2026-07-20): this grows into an
**LLM game generator** — and its first module, landing now because it is pure paper, is the
STORY kit: how to write an excellent story that can become a fun game.

**THE NON-INTERFERENCE LAW:** nothing in this folder gates, alters, or is depended on by the
Ziptide project. The street runs one way — these docs cite Ziptide as their worked example;
no project doc may link here as a requirement. Changes here never trigger project lanes,
never need PIPELINE amendments, and never touch the freeze.

## Contents
- `STORY_GENESIS.md` — the method: ten laws reverse-engineered from Ziptide's story bible +
  the craft imports + the ordered method with checkpoint tests + the quality gates. **The
  pre-pipeline: for a new game, this runs BEFORE `PIPELINE.md` Stage 0.**
- `STORY_BIBLE_TEMPLATE.md` — the fill-in skeleton: Ziptide's bible generalized
  section-by-section, with the per-world template and chapter format.

## Roadmap (extraction timing per ONE_SHOT_FRAMEWORK T5 — do not rush it)
The story kit lands first because it has zero code coupling. The REST of the Slipway (CI/gate
machinery, author patterns, booth, blackboard skeleton, the Genesis Interview, the Platform
Constitution) extracts ONLY after Ziptide's assembly line proves itself (PIPELINE Stage-5
checkpoint: the One-Session World). Extracting earlier extracts hope, not machinery.
