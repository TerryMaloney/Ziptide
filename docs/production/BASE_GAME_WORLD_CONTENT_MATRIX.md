## 0. Purpose

This is the single cross-domain view that was missing from the project. It does not replace the prose chapter files. It lets an operator see, for every base-game world:

- spatial/architecture family;
- physics or hazard identity;
- machine/primary verb;
- gear or power progression;
- opposition;
- recurring wreck/log and mystery device;
- production maturity.

It is the staging index for later machine serialization. Exact dialogue, flags, rewards and positions remain in the authoritative story/data documents.

### Production-state legend

- `MODEL` — active W000/W001 model band; incomplete product integration.
- `RECORD` — reference `WORLD_DATA` record and generated/graybox path exist.
- `CONCEPT` — approved visual North Star/reference exists.
- `SEED` — canonical prose seed only; machine production record still required.
- `SPECIAL` — deliberately unusual world requiring an explicit route type.

## 1. Cross-document conflicts and gaps exposed by this matrix

These must be resolved in data or canon before mass implementation. No operator may pick silently.

1. **W000 old record versus first-level contract:** old `GoToMarker` tutorial is superseded as a production target by the physical coupler/flight/salvage/reentry route. Machine data still needs migration.
2. **W001 opposition:** live/serialized contract centers drones; approved first-hour direction requires a signature creature/canal-stalker observation and non-lethal resolution. Preserve drones as maintenance pressure, but assign the creature explicitly.
3. **W002 gear conflict:** chapter canon introduces headlamp/scanner; `ABILITIES_AND_ARSENAL.md` lists Prism Beam at W002, while W006 is the clear canonical Prism world. Default recommendation: keep scanner at W002 and Prism at W006 unless Terry changes canon.
4. **World completion flag drift:** W001 uses historical `toxiccity_complete` beside later `W001_COMPLETE` language. One compatibility/migration rule is required.
5. **Gear tier identities:** many seeds say “tier 2/3” without stable item/upgrade IDs, recipes or effect-profile records.
6. **Guard/Pattern opposition:** Sable guards, generic guards and Pattern entities are story roles but do not all map cleanly to a current creature/combat definition.
7. **W013–W068 serialization:** every row remains prose-only until converted into production records.
8. **Derelict thread:** wreck/log content is complete in prose but lacks stable `derelictId`, ordered thread index, POI/interior recipe and persistence.
9. **Architecture overlays:** the matrix derives reusable families, but those references do not yet live in authoritative WorldSpec/WorldPack data.
10. **MK2 acquisition:** no world above canonically grants the Architect ship. It must be assigned deliberately.
11. **Earth Approach:** a required campaign leg exists between numbered worlds but has no explicit route/scene/data record.
12. **Ending completion experience:** ending story is strong; credits, replay, completion ceremony and post-game state still require production design.
13. **Art coverage:** W001–W004 have approved world North Stars; most later worlds have prose composition but no measured concept/spec/acceptance plate.
14. **Audio coverage:** nearly every row lacks stable audio event IDs and final assets.
15. **Side-mode reuse:** eligibility is not represented per row/item and is not audited.
