### Terry asked 2026-07-21: "what's our most important concept art that we need that we don't have yet — the top 30?" This is it. 2D only, free (nano banana), no code.

**Status:** 🔵 CONCEPT QUEUE — freeze-compatible (images only). The prior wave
(`TIER_C_CONCEPT_QUEUE.md`) built the FIRST-HOUR CAST — ship, skiff, Toxic City, gate, key,
Warden capital, Cal, RILL. **This wave builds the next few LEVELS and the CORE LOOP** — the

creatures below · skies SkyVista already owns · quantities (the tiling building kit stays

cinema, Prospect-film grounded realism, muted industrial palette. Color language: **tide
CYAN · lantern AMBER · Architect-seal DEEP-AMBER · Warden STERILE-WHITE.** Glyph-law: any
alien writing is INVENTED glyphs, never real-world script. Append to prompts as noted:
*"no text, no watermark"* (+ *"no people"* except where a tiny scale figure is asked).
