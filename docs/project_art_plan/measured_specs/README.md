## Shared gating order

1. Archive original keeper binaries and prompt provenance.
2. Validate JSON keeper sidecars.
3. Resolve reference-image authority splits.
4. Create simple proxy geometry—not final art.
5. Test standing adult, seated adult, and young-child reach.
6. Lock dimensions only after proxy evidence.
7. Assign Quest mesh/material/effect/collider budgets.
8. Resolve save/atomicity and owned-item recovery.
9. Receive exact M0 headset verdict and explicit freeze lift.
10. Assign a narrow implementation/Forge slice.
11. Compare built output against keeper.
12. Close only after device verdict.
