# THE PIPELINE — the one spine: story bible → shipped, living game
### Version 1.0 · created 2026-07-20 (Terry-approved) · THE LAW: the pipeline changes ONLY through this document (§A)

**What this is:** the single ordered route through the whole project. Every system, plan, and
doc in the repo serves exactly ONE stage below. When you don't know where something fits, or
what's next, or whether we're "on track" — this is the document that answers. Detail lives in
the linked docs; THIS doc owns only the order, the gates, and the checkpoints.
**How to read a stage:** INPUTS → MACHINES (the docs/systems that do the work) → GATES (what
must be green) → **CHECKPOINT** (the named, recorded human verdict that closes the stage — the
`QUEST_GOLDEN_CHECKPOINT.md` template: entry criteria, evidence table, verdict, sign-off) →
OUTPUTS. Stages 6+ overlap in time; checkpoints still close IN ORDER.
**Status legend:** ✅ done · 🟢 built/proven · 🟡 in flight · 🔵 planned on paper · ⚪ not started.
